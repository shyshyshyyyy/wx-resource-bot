# 授权对接说明（授权生成器 v2）

## 一、在授权生成器里新增本软件

打开 `授权生成器.exe` → 左侧「我的软件」→ 右上「+ 新增软件」，按下面填：

| 字段 | 填什么 |
|---|---|
| **软件名称** | `微信资源搜索机器人`（只是显示名，随便起，不影响验签） |
| **appId** | `wx-resource-bot` ← **必须一字不差** |
| 分类 | `桌面端` |
| 默认有效期(天) | `365`（试用可填 30） |
| 备注 | 可留空 |

> ⚠️ 生成器默认列表里已有一条「微信云搜机器人 / `weixin-cloud-search`」，
> 那是旧的 v2.7.3 产品，**不要复用**，本软件要单独新增一条。

appId 已经写死在软件里（`license.py` 的 `APP_ID`）。
**一旦开始对外发码就不能再改**，否则所有已发出的授权码会失效。

## 二、签发流程

1. 客户打开软件 → 左侧「授权激活」→ 复制**本机机器码**（形如 `7E16-9A96-1F02-E54C`）
2. 生成器 → 「签发授权」→ 选软件「微信资源搜索机器人（wx-resource-bot）」→ 粘贴机器码 → 选类型/天数 → 「生成并签名授权」
3. 把生成的**整段 JSON**（从 `{` 到 `}`）复制发给客户
4. 客户粘贴到授权码输入框 → 点「激活」

## 三、授权码长什么样

```json
{
  "payload": {
    "appId": "wx-resource-bot",
    "licenseId": "L-20260909041240",
    "machineCode": "7E16-9A96-1F02-E54C",
    "type": "period",
    "features": ["*"],
    "issuedAt": "2026-09-09T04:12:40Z",
    "expiresAt": "2027-09-09T04:12:40Z",
    "note": ""
  },
  "signature": "cZy2Bf3Pv5Fi..."
}
```

- `type`：`trial` 试用 / `period` 按期 / `permanent` 永久 / `feature` 按功能
- `permanent` 时 `expiresAt` 为 `null` → 软件显示「永久」
- 签名算法：RSA-2048 + PKCS1v15 + SHA256，签名对象是
  `json.dumps(payload, sort_keys=True, separators=(",",":"), ensure_ascii=False)` 的 UTF-8 字节

## 四、密钥

已将本软件内嵌公钥换成生成器的 `keys/public.pem`（同一对密钥）。
换密钥只影响验签，私钥始终只在生成器本地，客户端无法伪造。

## 五、会拒绝的几种情况（软件端提示文案）

| 情况 | 提示 |
|---|---|
| 授权码被改过一个字 | 激活码签名无效（伪造或被篡改） |
| 拿别的软件/别的机器的码 | 激活码与本机不匹配（机器码不符） |
| appId 不是本软件 | 该授权码不属于本软件（appId=xxx） |
| 过了 expiresAt | 激活码已过期 |
| 系统时间往回调超过 1 天 | 系统时间异常（检测到时间回拨），请校准后重试 |

软件端仍兼容旧格式 `base64url(payload).base64url(sig)` 的授权码。
