# 微信资源搜索机器人

一款运行在 Windows 上的微信个人号资源搜索机器人：在微信里发「**搜索 关键词 网盘**」，机器人调用盘搜接口找资源，再**把资源转存到你自己的网盘账号**、生成**你自己的分享链接**回发给对方。单文件 exe，双击即用，无需安装 Python。

> 本仓库发布的是**编译好的 exe + 使用说明**。源码与开发环境不在此仓库中。

---

## 功能特性

- **微信监听**：基于 `wxauto4`（免费）/ `wxautox4`（付费增强）个人号，监听私聊与群聊，触发词自动响应。
- **盘搜接口**：对接 pansou 类搜索源，默认填好远程演示站，开箱即用；也支持本地 `pansou.exe`。
- **7 大网盘自动转存**：夸克 / 百度 / UC / 阿里云 / 迅雷 / 光鸭 / 移动云盘，转存引擎在本地实现（不依赖服务器接口）。
- **账号池轮转**：按网盘分组管理账号，失效自动跳过，把单账号频率压下来。
- **群聊隔离**：群内多人同时搜索互不串号，回复精准 @ 发起人。
- **消息模板**：触发词、搜索中、结果、转存成功/失败、过期等全环节文案均可自定义。
- **分享转链**：把搜到的资源转存到自己的网盘并生成自有分享链接，可群发。
- **授权体系**：离线 RSA-2048 机器码授权，未激活功能受限。
- **内置配置面板**：PySide6 单 exe（`--windowed`，不弹黑窗）。
- **本地表格导入资源**：支持 xlsx / csv 导入，导入后并入「搜索」结果混排；每行可标「是否自己的资源」，标「是」的项获取时**跳过转存、直接回原链接**，标「否」走正常转存引擎。
- **定时清理转存文件**（移植自网盘搜索站 delete_search）：按保留期自动删除机器人转存到你网盘的文件，避免长期占用空间（旧分享链接会随之失效，与搜索站行为一致）。

## 运行环境

- Windows 10 / 11，且**微信 PC 版已登录并保持登录状态**（机器人通过 UI 自动化操作微信窗口）。
- 单文件 exe，无需安装 Python 环境与任何依赖。
- 首次运行会在 exe **同级目录**生成 `data/` 配置目录（升级时保留，不会丢配置）。

---

## 快速开始

1. 下载本仓库的 `微信资源搜索机器人.exe`。
2. 双击运行。建议右键「**以管理员身份运行**」，避免微信窗口句柄权限问题。
3. 在弹出的配置面板里按需配置：
   - **盘搜接口**：默认已填远程演示站；想长期稳定用，请改成你自己的 pansou 地址（见下方「本地盘搜」）。
   - **网盘账号**：填入对应网盘的 Cookie / refresh_token，启用并选择转存目标文件夹。
   - **消息模板**：按需修改触发词与各环回复文案。
   - **授权激活**：填入管理员下发的授权码。
4. 点「启动机器人」，在微信里发「`搜索 三体 夸克`」即可收到结果。

> ⚠️ 默认的远程盘搜演示站仅供体验，不稳定也不建议长期依赖，请尽快换成自建 pansou。

## 配置说明

所有配置保存在 exe 同级的 `data/config/config.json`，面板做的修改即时落盘，升级 exe 时这个目录保留即可。

主要配置项：

- `search.remote.base_url`：远程盘搜接口地址（默认 `http://38.92.9.77:8888`）。
- `search.default_types`：默认启用的网盘类型列表（quark/baidu/uc/aliyun/xunlei/guangya/mobile）。
- `transfer.accounts`：各网盘账号（cookie / refresh_token / 转存目录）。
- `transfer.cleanup`：定时清理（`enabled` 是否开启、`time` 每天执行时刻 HH:MM、`older_than_days` 保留天数）。
- `imported`：本地导入资源（`enabled` 是否并入搜索、`path` 最近一次导入表格路径）。
- `wechat.listen_groups`：要监听的群名；`whitelist` / `blacklist` 控制私聊范围。
- `templates`：全环节回复模板，支持 `{keyword}` `{title}` `{share_url}` `{password}` 等占位符。
- `triggers`：触发指令（`search_cmd` 默认「搜索」，`next_page_cmd` 默认「下一页」）。

## 本地盘搜（可选）

pansou 官方未发布 Windows 二进制，默认走远程接口。若要用本地盘搜：

1. 把编译好的 `pansou.exe` 放到 `bin/` 目录。
2. 在面板「盘搜接口」里把模式切到 `local` 或 `both`，填入本地端口与频道。

## 本地资源导入（xlsx / csv）

把你自己整理的资源表格导入机器人，用户搜索时一并返回；自有资源可跳过转存。

**表格模板**（表头含以下关键字即可，列顺序不限；支持中英文表头）：

| 列 | 说明 | 必填 |
|----|------|------|
| 名称 | 资源标题 | ✅ |
| 链接 | 分享链接 | ✅ |
| 提取码 | 提取码 / 密码 | 可选 |
| 网盘类型 | 夸克/百度/UC/阿里云/迅雷/光鸭/移动；留空按链接域名自动识别 | 可选 |
| 是否自己的 | 是/否/1/0/true/false；标「是」的项获取时跳过转存、直接回原链 | 可选，默认「否」 |

**用法**：面板「盘搜接口 → 本地资源导入」点「选择表格导入」，匹配到的「是否自己的 = 是」项在用户回数字获取时直接返回原链接，不做转存。

> **支持导入多个表格**：每个表格独立保存，导入第二个不会清除第一个；面板列表里可看到每个已导入文件（文件名 / 条数 / 时间），点「移除选中」单独删掉某个表格，或「清空全部」一键清除。
> 同一文件再次导入会更新其内容（不会重复计数）。导入数据按来源文件路径区分。

## 授权

采用离线机器码授权：

- 机器码由多硬件因子（主板 UUID / 系统 MachineGuid / CPU / 卷序列号等）生成，并写入 `machine.lock` 本地锁定；硬件小改动（换网卡、加硬盘）不会让授权失效。
- 授权码格式：`base64url(payload).base64url(签名)`，RSA-2048 验签，无法伪造。
- 源码环境运行跳过授权，方便开发调试；打包后的 exe 必须激活。

## 常见问题

**Q：机器人没反应？**
- 确认微信 PC 版已登录且窗口未被最小化到托盘（部分微信版本最小化后会断开 UI 自动化）。
- 确认监听的群 / 私聊在面板里已开启，触发词拼写正确。

**Q：转存提示「还没有配置可用账号」？**
- 去「网盘账号」填入对应网盘的 Cookie / refresh_token 并启用。

**Q：盘搜一直搜不到？**
- 远程演示站不稳定，请自建 pansou 并修改 `search.remote.base_url`。
